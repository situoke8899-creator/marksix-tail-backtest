# 澳门六合彩尾数策略回测系统

Next.js 版本，支持澳门开奖历史数据读取，并对固定尾数组合进行近 20 / 30 / 50 期回测。

## 功能

- 最新开奖展示
- 下一期 8 个尾数参考与复制按钮
- 10 套尾数方案排行
- 10 个档位当期开奖统计
- 近 20 期开奖冻结统计：每期开奖后保存当时 10 档位中 / 不中结果，后续不会随新排名改写
- 20 / 30 / 50 期命中率、最大连错、当前连错和覆盖率
- 尾数热度与遗漏统计

## 本地运行

```bash
npm install
npm run dev
```

## Vercel 部署

上传完整项目到 GitHub 后，在 Vercel 选择该仓库，Framework 选择 Next.js，点击 Deploy。
